# productivity-journal

A React developer diary app for tracking daily coding notes, tasks, moods, and productivity charts.

## Features

- Daily journal entries for learning, building, problems, solutions, and next goals
- Mood tracking with weekly chart data
- Task tracker with priorities, filters, completion status, and deletion
- Productivity dashboard with weekly task, mood, consistency, and priority charts
- Local storage persistence

## Tech Stack

- React
- Vite
- Tailwind CSS
- Recharts

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
